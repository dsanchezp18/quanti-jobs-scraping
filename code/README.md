# Code

## Purpose
Contiene el codigo reproducible del proyecto, separado entre construccion de muestra y analisis.

## Contents
- `cleaning/`: scripts que transforman los cortes de entrada en datasets analiticos.
- `analysis/`: scripts que producen tablas, figuras y objetos resumen.

## Naming Convention
Los scripts usan prefijos numericos para marcar el orden de ejecucion.

## Dependencies
Se ejecutan desde `MASTER.R` en la raiz del repositorio.
