# Outputs

## Purpose
Agrupa las salidas del analisis reproducible: figuras, tablas y objetos resumen.

## Contents
- `figures/`: graficos exportados.
- `tables/`: tablas CSV listas para usar en el articulo.
- `mercado_datos_resumen.rds`: objeto consolidado con resultados.

## Naming Convention
Las figuras y tablas usan nombres descriptivos del hallazgo o bloque analitico.

## Dependencies
Se escriben desde `code/analysis/01_market_tools_outputs.R`.
